# Seat Booking Module

## Technology Stack
- Node.js
- Express.js
- PostgreSQL
- Socket.IO
- HTML, CSS and JavaScript

## Implemented Features
- Seat availability
- Temporary seat locking
- Five-minute countdown timer
- Automatic expired seat release
- Duplicate seat lock prevention
- Real-time seat status updates
- Booking confirmation
- Booking history
- My Bookings interface

## Installation

1. Install Node.js and PostgreSQL.
2. Open the seat-booking-module folder.
3. Run npm install.
4. Create a PostgreSQL database named seat_booking.
5. Import sql/schema.sql using psql.
6. Copy .env.example to .env.
7. Configure your database password.
8. Run node server.js.

## Application URLs

Seat Booking:
http://localhost:5002/booking/

My Bookings:
http://localhost:5002/booking/my-bookings.html
